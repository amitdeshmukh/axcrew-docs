## What is AxCrew?

AxCrew is a framework for building and managing crews of AI agents on top of [AxLLM](https://axllm.dev).

## Installation

Install AxCrew and Ax peer dependencies:

```bash
npm install @amitdeshmukh/ax-crew
npm install @ax-llm/ax @ax-llm/ax-tools
```

<Callout type="info">
  Requirements: Node.js >= 21
</Callout>

## Environment Setup

Create a `.env` file and provide provider keys:

```bash
OPENAI_API_KEY=...
ANTHROPIC_API_KEY=...
GEMINI_API_KEY=...
```

In each agent config, set `providerKeyName` to the env var name.

## Minimal Setup

```typescript
import { AxCrew } from '@amitdeshmukh/ax-crew';

const config = {
  crew: [
    {
      name: 'Manager',
      description: 'Completes a task or responds to a question',
      executionMode: 'axgen', // "axagent" | "axgen"
      signature: 'task:string -> reply:string',
      provider: 'openai',
      providerKeyName: 'OPENAI_API_KEY',
      ai: {
        model: 'gpt-4o-mini',
        temperature: 0.2,
      },
    },
  ],
};

const crew = new AxCrew(config);
await crew.addAllAgents();

const manager = crew.agents?.get('Manager');
const { reply } = await manager.forward({
  task: 'Create a launch plan for a new product feature',
});

console.log(reply);
```

## RLM Mode (AxAgent)

When using `executionMode: "axagent"` with modern Ax RLM behavior, provide `axAgentOptions` with required fields:

- `axAgentOptions.runtime`: `AxJSRuntime`
- `axAgentOptions.contextFields`: required (empty array allowed)

```typescript
import { AxJSRuntime, AxJSRuntimePermission } from '@ax-llm/ax';

const runtime = new AxJSRuntime({
  permissions: [AxJSRuntimePermission.TIMING],
});

const rlmConfig = {
  crew: [
    {
      name: 'Analyzer',
      description: 'Analyzes runtime-backed context',
      executionMode: 'axagent',
      signature: 'context:string, query:string -> answer:string',
      provider: 'google-gemini',
      providerKeyName: 'GEMINI_API_KEY',
      ai: { model: 'gemini-2.5-flash', temperature: 0 },
      axAgentOptions: {
        runtime,
        contextFields: ['context'],
      },
    },
  ],
};
```

The external API does not change. Continue to call `forward` / `streamingForward`; AxCrew routes internally by `executionMode`.
