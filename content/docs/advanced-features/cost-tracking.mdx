---
title: Cost Tracking
description: Track token usage, request metrics, and estimated USD costs in AxCrew
---

AxCrew exposes cost and usage through the metrics API.

## What Is Tracked

- request counts and error rate
- streaming vs non-streaming request counts
- prompt/completion/total tokens
- estimated cumulative USD cost
- function/tool call counts and latency

## Per-Agent Metrics

```typescript
const planner = crew.agents?.get('Planner');

await planner?.forward({ task: 'Create a rollout plan' });

const m = (planner as any).getMetrics?.();
console.log(m);
/*
{
  requests: {
    totalRequests: number,
    totalErrors: number,
    errorRate: number,
    totalStreamingRequests: number,
    durationMsSum: number,
    durationCount: number
  },
  tokens: {
    promptTokens: number,
    completionTokens: number,
    totalTokens: number
  },
  estimatedCostUSD: number,
  functions: {
    totalFunctionCalls: number,
    totalFunctionLatencyMs: number,
    details?: [{ name, calls, totalLatencyMs }]
  }
}
*/
```

## Crew Metrics

```typescript
const crewMetrics = crew.getCrewMetrics();

console.log('Crew USD:', crewMetrics.estimatedCostUSD);
console.log('Crew tokens:', crewMetrics.tokens.totalTokens);
```

## Reset Metrics/Costs

```typescript
crew.resetCosts();
// or
crew.resetCrewMetrics();
```

## Mode Compatibility (`axagent` and `axgen`)

Metrics/cost tracking works regardless of per-agent execution mode:

- `executionMode: "axagent"`
- `executionMode: "axgen"`

This includes AxAgent RLM mode configured with `axAgentOptions`.

## Session-Level Pattern

```typescript
crew.resetCosts();

await crew.agents?.get('Planner')?.forward({ task: 'Draft architecture options' });
await crew.agents?.get('Writer')?.forward({ task: 'Write summary' });

const sessionMetrics = crew.getCrewMetrics();
crew.state.set('session.metrics', sessionMetrics);

console.log('Session USD:', sessionMetrics.estimatedCostUSD);
console.log('Session tokens:', sessionMetrics.tokens.totalTokens);
```

## Important Notes

- Legacy cost APIs (`getLastUsageCost`, `getAccumulatedCosts`, `getAggregatedCosts`) are superseded by metrics APIs.
- Use metrics snapshots (`getMetrics`, `getCrewMetrics`) for production reporting.
