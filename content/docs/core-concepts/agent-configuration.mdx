Each agent in your crew is defined by a configuration object.

## Full Shape

```typescript
{
  name: "AgentName",                     // Required
  description: "What this agent does",   // Required
  executionMode: "axagent",              // Optional: "axagent" | "axgen" (default: axagent)
  signature: "input:type -> output:type",// Required
  provider: "openai",                    // Required
  providerKeyName: "OPENAI_API_KEY",     // Required
  ai: { model: "gpt-4o-mini", temperature: 0.2 }, // Required

  // Optional
  axAgentOptions: {},
  definition: "...",
  prompt: "...",                         // alias for definition
  providerArgs: {},
  options: { debug: false },
  agents: ["OtherAgent"],
  functions: ["FunctionName"],
  mcpServers: {},
  examples: [],
  ace: {}
}
```

## Required Fields

| Field | Description |
|---|---|
| `name` | Unique agent name in the crew |
| `description` | Agent purpose and behavior summary |
| `signature` | Input/output contract |
| `provider` | Ax provider ID |
| `providerKeyName` | Env var containing API key |
| `ai` | Model settings passed to Ax |

## Execution Mode

Each agent can run in one of two modes:

- `axagent` (default): modern AxAgent capabilities, including RLM features
- `axgen`: AxGen execution

```json
{
  "name": "Planner",
  "executionMode": "axgen",
  "signature": "task:string -> plan:string",
  "provider": "google-gemini",
  "providerKeyName": "GEMINI_API_KEY",
  "ai": { "model": "gemini-2.5-flash", "temperature": 0 }
}
```

AxCrew routes internally by `executionMode`. The external invocation API remains `forward` / `streamingForward`.

## AxAgent RLM Options (`axAgentOptions`)

Use `axAgentOptions` when `executionMode` is `axagent`.

Mandatory for RLM mode:

- `axAgentOptions.runtime`: `AxJSRuntime` instance
- `axAgentOptions.contextFields`: required (empty array allowed)

```typescript
import { AxJSRuntime, AxJSRuntimePermission } from '@ax-llm/ax';

const runtime = new AxJSRuntime({
  permissions: [AxJSRuntimePermission.TIMING],
});

const agent = {
  name: 'Analyzer',
  executionMode: 'axagent',
  signature: 'context:string, query:string -> answer:string',
  provider: 'google-gemini',
  providerKeyName: 'GEMINI_API_KEY',
  ai: { model: 'gemini-2.5-flash', temperature: 0 },
  axAgentOptions: {
    runtime,
    contextFields: ['context'],
    maxTurns: 20,
    maxSubAgentCalls: 40,
    mode: 'simple',
  },
};
```

## Persona (`definition` / `prompt`)

- `definition`: preferred detailed system program
- `prompt`: alias for `definition`
- If both are present, `definition` wins

## Provider Arguments (`providerArgs`)

Some providers require top-level arguments outside `ai` (for example, Azure deployment settings). Pass them using `providerArgs`; AxCrew forwards them to Ax unchanged.

## Dependencies and Tools

- `agents`: sub-agent names
- `functions`: tool/function names from the registry
- `mcpServers`: MCP transport configs

AxCrew resolves dependency order automatically with `addAllAgents()` or `addAgentsToCrew()`.

## Signature Format

```text
inputName:inputType "description" -> outputName:outputType "description"
```

Examples:

```text
task:string -> plan:string
```

```text
query:string, limit:number -> results:string[], total:number
```
