A crew is a collection of agents with shared state and coordinated dependency management.

## What a Crew Gives You

- shared state across all agents
- automatic dependency-aware initialization
- composition via sub-agents and tools
- crew-wide metrics and cost reporting

## Crew Config Shape

```json
{
  "crew": [
    {
      "name": "Calculator",
      "description": "Performs mathematical calculations",
      "executionMode": "axagent",
      "signature": "equation:string -> result:number",
      "provider": "openai",
      "providerKeyName": "OPENAI_API_KEY",
      "ai": { "model": "gpt-4o-mini", "temperature": 0 }
    },
    {
      "name": "Planner",
      "description": "Creates plans",
      "executionMode": "axgen",
      "signature": "task:string -> plan:string",
      "provider": "google-gemini",
      "providerKeyName": "GEMINI_API_KEY",
      "ai": { "model": "gemini-2.5-flash", "temperature": 0 }
    },
    {
      "name": "Manager",
      "description": "Coordinates Planner and Calculator",
      "signature": "question:string -> answer:string",
      "provider": "anthropic",
      "providerKeyName": "ANTHROPIC_API_KEY",
      "ai": { "model": "claude-3-7-sonnet-latest", "temperature": 0.2 },
      "agents": ["Planner", "Calculator"]
    }
  ]
}
```

## Initialize a Crew

```typescript
import { AxCrew, AxCrewFunctions } from '@amitdeshmukh/ax-crew';

const crew = new AxCrew(config, AxCrewFunctions);
```

## Add Agents

### Add all

```typescript
await crew.addAllAgents();
```

### Add selected (dependency-aware)

```typescript
await crew.addAgentsToCrew(['Manager']);
```

### Add one (manual dependency handling)

```typescript
await crew.addAgent('Calculator');
```

## Shared State

```typescript
crew.state.set('project', 'alpha');

const planner = crew.agents?.get('Planner');
planner?.state.set('plan', 'v1');

const manager = crew.agents?.get('Manager');
console.log(manager?.state.getAll());
```

## Metrics and Cost Tracking

Use metrics APIs instead of legacy aggregated-cost APIs:

```typescript
const manager = crew.agents?.get('Manager');
await manager?.forward({ question: 'How should we ship this?' });

// Per-agent
const managerMetrics = (manager as any)?.getMetrics?.();
console.log(managerMetrics?.estimatedCostUSD);

// Crew-wide
const crewMetrics = crew.getCrewMetrics();
console.log(crewMetrics.estimatedCostUSD);
console.log(crewMetrics.tokens.totalTokens);

// Reset when needed
crew.resetCosts();
```

## Cleanup

```typescript
crew.destroy();
```
