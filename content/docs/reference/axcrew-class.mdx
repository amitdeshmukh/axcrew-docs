`AxCrew` is the main orchestration class for creating and managing agent crews.

## Constructor

```typescript
constructor(
  crewConfig: AxCrewConfig,
  functionsRegistry?: FunctionRegistryType,
  options?: AxCrewOptions,
  crewId?: string
)
```

Parameters:

- `crewConfig`: required config object with `crew` array
- `functionsRegistry`: optional function/tool registry
- `options`: optional settings (`debug`, `telemetry`)
- `crewId`: optional explicit crew identifier

## Properties

### `agents`

```typescript
agents: Map<string, StatefulAxAgent> | null
```

Holds initialized agent instances keyed by name.

### `state`

```typescript
state: StateInstance
```

Shared mutable state for the entire crew.

### `crewId`

```typescript
crewId: string
```

Crew-scoped identifier used by metrics.

## Lifecycle / Initialization

### `addAgent(agentName)`

```typescript
addAgent(agentName: string): Promise<void>
```

Adds a single agent by name. Manual dependency ordering required.

### `addLazyAgent(agentName)`

```typescript
addLazyAgent(agentName: string): void
```

Adds a lightweight proxy for the agent. The tool schema (name, description, parameters) is built immediately from the crew config, but the full agent — including MCP server connections, AI client setup, and function resolution — is only created when the agent is first invoked.

Use this for sub-agents that may not be needed on every request, especially those with stdio MCP servers that spawn a process on init.

```typescript
// Eager: spawns the npx MCP server immediately
await crew.addAgent('CreateChart');

// Lazy: instant — MCP server only starts if Manager delegates to CreateChart
crew.addLazyAgent('CreateChart');
```

### `addAgentsToCrew(agentNames)`

```typescript
addAgentsToCrew(agentNames: string[]): Promise<Map<string, StatefulAxAgent> | null>
```

Adds a subset of agents and resolves dependencies automatically.

### `addAllAgents()`

```typescript
addAllAgents(): Promise<Map<string, StatefulAxAgent> | null>
```

Adds all configured agents with dependency ordering.

### `destroy()`

```typescript
destroy(): void
```

Clears references and shared crew state.

## ACE Feedback Routing APIs

### `applyTaskFeedback(params)`

```typescript
applyTaskFeedback(params: {
  taskId: string;
  feedback: string;
  strategy?: 'all' | 'primary' | 'weighted';
}): Promise<void>
```

Applies feedback across agents involved in a task.

### `trackAgentExecution(taskId, agentName, input)`

```typescript
trackAgentExecution(taskId: string, agentName: string, input: any): void
```

Tracks execution context for ACE feedback routing.

### `recordAgentResult(taskId, agentName, result)`

```typescript
recordAgentResult(taskId: string, agentName: string, result: any): void
```

Stores output used for feedback propagation.

### `getTaskAgentInvolvement(taskId)`

```typescript
getTaskAgentInvolvement(taskId: string): {
  rootAgent: string;
  involvedAgents: string[];
  taskInput: any;
  agentResults: Map<string, any>;
  duration?: number;
} | null
```

Returns execution context for a previously tracked task.

### `cleanupOldExecutions(maxAgeMs?)`

```typescript
cleanupOldExecutions(maxAgeMs?: number): void
```

Removes stale execution-history entries (default 1 hour).

## Usage Example

```typescript
import { AxCrew, AxCrewFunctions } from '@amitdeshmukh/ax-crew';

const crew = new AxCrew(config, AxCrewFunctions, {
  telemetry: { tracer, meter },
});

await crew.addAllAgents();

const planner = crew.agents?.get('Planner');
const res = await planner?.forward({ task: 'Plan migration' });

console.log(res);
console.log(crew.getCrewMetrics());

crew.destroy();
```
