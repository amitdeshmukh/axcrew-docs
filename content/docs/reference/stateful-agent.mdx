---
title: StatefulAxAgent Class
description: API reference for AxCrew's stateful agent wrapper
---

`StatefulAxAgent` is AxCrew's agent wrapper that:

- keeps access to shared crew state
- routes execution by `executionMode` (`axagent` or `axgen`)
- records built-in metrics and estimated cost
- supports ACE hooks

You normally obtain instances from `crew.agents` after initialization.

## Properties

### `state`

```typescript
state: StateInstance
```

Shared state instance used by all agents in the crew.

## Core Methods

### `forward(...)`

```typescript
forward(values: Record<string, any>, options?): Promise<Record<string, any>>
forward(ai: AxAI, values: Record<string, any>, options?): Promise<Record<string, any>>
```

Runs a non-streaming invocation.

### `streamingForward(...)`

```typescript
streamingForward(values: Record<string, any>, options?): AxGenStreamingOut<any>
streamingForward(ai: AxAI, values: Record<string, any>, options?): AxGenStreamingOut<any>
```

Runs a streaming invocation.

### `getUsage()`

```typescript
getUsage(): AxProgramUsage[]
```

Returns usage from the active engine (`AxAgent` or `AxGen` depending on execution mode).

### `resetUsage()`

```typescript
resetUsage(): void
```

Resets underlying usage counters.

## Metrics Methods

### `getMetrics()`

```typescript
getMetrics(): MetricsSnapshot
```

Returns request/token/cost/function metrics for this agent.

### `resetMetrics()`

```typescript
resetMetrics(): void
```

Resets metrics for this agent only.

## Compatibility Helpers

### `setExamplesCompat(examples)`

```typescript
setExamplesCompat(examples: Readonly<Array<Record<string, any>>>): void
```

Sets examples across Ax runtime variants.

### `setDescriptionCompat(description)`

```typescript
setDescriptionCompat(description: string): void
```

Updates description/program prompt across Ax runtime variants.

## Deprecated Cost Methods

These methods remain for compatibility but return `null` and should not be used for reporting:

- `getLastUsageCost()`
- `getAccumulatedCosts()`

Use `getMetrics()` and `crew.getCrewMetrics()` instead.

## ACE Methods

When ACE is configured, the agent supports:

- `initACE(...)`
- `optimizeOffline(...)`
- `applyOnlineUpdate(...)`
- `getPlaybook()`
- `applyPlaybook(...)`

## Example

```typescript
const planner = crew.agents?.get('Planner');

const result = await planner?.forward({ task: 'Draft migration steps' });
console.log(result);

const metrics = (planner as any)?.getMetrics?.();
console.log(metrics?.estimatedCostUSD);
```
