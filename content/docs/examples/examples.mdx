## New RLM Examples

### `rlm-long-task.ts`

Demonstrates AxAgent RLM configuration for long-running analysis with context management:

- `executionMode: "axagent"`
- mandatory `axAgentOptions.runtime`
- mandatory `axAgentOptions.contextFields`
- cost/usage printed at the end (agent + crew)

### `rlm-shared-fields.ts`

Demonstrates AxAgent RLM shared fields and sub-agent propagation:

- parent agent with shared/context fields
- child agents with field include/exclude behavior
- cost/usage printed at the end (agent + crew)

## Minimal Example Pattern

```typescript
import { AxCrew } from '@amitdeshmukh/ax-crew';

const crew = new AxCrew(config);
await crew.addAllAgents();

const manager = crew.agents?.get('Manager');
const result = await manager?.forward({ task: 'Draft a release plan' });

console.log(result);

const managerMetrics = (manager as any)?.getMetrics?.();
const crewMetrics = crew.getCrewMetrics();

console.log('Manager USD:', managerMetrics?.estimatedCostUSD ?? 0);
console.log('Crew USD:', crewMetrics.estimatedCostUSD);

crew.destroy();
```

## Run Examples

```bash
git clone https://github.com/amitdeshmukh/ax-crew.git
cd ax-crew
npm install

# set env keys in .env
npx tsx examples/rlm-long-task.ts
npx tsx examples/rlm-shared-fields.ts
```

## Why These Examples Matter

The RLM examples specifically validate that:

- external invocation API is unchanged (`forward`/`streamingForward`)
- AxCrew internally routes by `executionMode`
- built-in metrics and telemetry continue to accumulate correctly in RLM mode
